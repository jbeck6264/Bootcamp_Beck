Apex One Luxury Motors

Project Overview

Apex One Luxury Motors is a Java 17 console-based dealership application. I created this program to manage a luxury vehicle inventory. Users can search for vehicles, view the inventory, add new vehicles, and remove vehicles.

How I Built It

I built this project using Java 17 and object-oriented programming. I separated the program into different classes so each class has its own responsibility.

Vehicle: Stores information about each vehicle, including VIN, year, make, model, type, color, mileage, and price.

Dealership: Manages the dealership information and vehicle inventory. It also handles searching, adding, and removing vehicles.

DealershipFileManager: Reads vehicle information from a CSV file and saves inventory changes back to the file.

UserInterface: Displays the dealership menu and allows users to interact with the program.

Main: Starts the application.

Features

Search vehicles by price range.

Search by make and model.

Search by year range.

Search by color.

Search by mileage range.

View the dealership inventory.

Add new vehicles.

Remove vehicles by VIN.

Save inventory changes to a CSV file.
