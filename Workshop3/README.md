Online Store

Description

This is a simple online store application created using Java 17.

Features

Display all products.

Search products by name.

Search products by price range.

Search products by department.

Add products to shopping cart.

Remove products from shopping cart.

Display shopping cart total.

Technologies Used

Java 17

IntelliJ IDEA

Maven

How to Run

Open the project in IntelliJ IDEA.

Open Main.java.

Run the Main.java file.

Follow the menu options to use the online store.
